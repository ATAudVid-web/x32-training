# Lesson Audio Files

Pre-generated MP3 audio files for X32 Training Hub lessons.

Generated automatically by the **Generate Lesson Audio** GitHub Actions workflow
using Microsoft Edge TTS (`edge-tts` Python package) with voice `en-US-GuyNeural`.

## Files
- `lesson-1.mp3` through `lesson-8.mp3` — one per lesson

## Regenerate
1. Go to **Actions** tab in GitHub
2. Select **Generate Lesson Audio**
3. Click **Run workflow**

Or push a change to `index.html` — the workflow triggers automatically.
